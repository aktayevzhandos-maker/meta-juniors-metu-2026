# Meta Juniors — AI in Engineering 2026

- До объявления кейса готовить только универсальные инструменты. Не проводить Discovery, AS-IS/TO-BE, предметное проектирование и не создавать продукт, UI, API или предметную БД.
- После получения кейса: разбор задачи → проблема и пользователи → Discovery → AS-IS/TO-BE → ценность → выбор подхода → минимальная архитектура → MVP → проверки и метрики → демо → питч.
- Отличать требования положения от рекомендаций. Отсутствие запрета не считать разрешением. До использования предварительного кода, AI-агентов и внешних сервисов для данных кейса уточнить правила у организаторов.
- Не привязывать решение к OpenAI: $2000 кредитов — ресурс, а не обязательство. Рассматривать классические алгоритмы, специализированный ML, открытые модели и разные API по задаче.
- Выбирать подход по качеству, задержке, стоимости, доступности, ресурсам, сложности интеграции, надёжности демо, лицензиям и пилоту за 30–90 дней. После кейса проверять кандидатов на небольшом репрезентативном наборе.
- Никаких платных запросов без разрешения; не скачивать крупные веса и не делать объёмные установки или глобальные изменения без подтверждения. Не сохранять ключи, персональные или закрытые данные в Git и логи.
- Стек команды: Python/FastAPI, React/TypeScript/Vite, Tailwind, PostgreSQL, Docker Compose, Git/GitHub. Использовать имеющиеся инструменты и локальные окружения; зависимости фиксировать. Изолированная .venv использует Python 3.12.
- После кейса согласовать API-контракт; разделить frontend/backend/ML-задачи. Короткие ветки от main, один ответственный за общие конфиги и интеграцию; main сохранять запускаемой. Отмечать проверенные версии тегами demo-*.
- Положение: команда до 3 человек, капитан и роли data/ML, предметный инженер/технолог, разработчик/UI; обязательные материалы — код, README до страницы (задача, данные, метод, метрики до/после, ограничения), Streamlit или видео 1–2 минуты, до 6 слайдов, источники и лицензии данных/моделей. Питч 3 минуты + 2 минуты вопросов.
- Оценка: технологичность 35, эффект 25, внедрение 15, нормы 10, питч/дизайн 15. Биометрия без согласий запрещена; CV без распознавания лиц и идентификации; оборудование только в безопасном деморежиме.
- Уточнить: фактический дедлайн кода (в положении 24 часа, но даты 20.11 09:00 — 21.11 13:00 дают 28 часов), правила заранее подготовленных материалов и AI, внешних данных/API, обновления декларации данных после брифа и доступа к репозиторию.
- Не создавать лишнюю документацию или универсальный AI-фреймворк. Minimum Preparation, Maximum Readiness.

# AIID — интеллектуальный подбор экспертов

**Meta Juniors · AI in Engineering 2026 · финальный MVP.** Координатор Альянса описывает задачу обычным языком и получает топ-3 экспертов с объяснениями вместо поиска через личные контакты. Цель кейса — Hit@3 не ниже 80% и подбор до 30 секунд.

## Возможности и метод

Текстовый поиск на русском, казахском и английском; дополнительные фильтры отрасли, города и стажа; доступность, профиль и сравнение кандидатов; реестр с предпросмотром и импортом CSV; аналитика топ-5 востребованных компетенций. Занятые эксперты ранжируются ниже. Аналитика хранит агрегаты спроса без текстов запросов.

**Подбор:** BM25 + Snowball + локальный словарь компетенций и синонимов, распознавание отрицаний и границ опыта. Объяснения опираются на поля анкет; частичные совпадения показывают невыполненные условия. Процент — покрытие распознанных требований, не вероятность пригодности.

**Локальный ИИ:** Ollama / `qwen2.5:1.5b` для дополнительного сравнения топ-3. Сервер заранее вычисляет факты, ограничивает JSON-ответ допустимыми формулировками и проверяет его. Модель не ранжирует экспертов. При её недоступности поиск и карточки работают. Qwen проверена командой на демонстрационном ноутбуке; время сравнения измеряется отдельно от поиска.

## Данные и результаты

[CSV UTF-8](data/experts.csv): 120 вымышленных профилей, 8 отраслей, 6 городов; без реальных персональных данных. [CSV для Excel с BOM](data/experts_utf8.csv). Генератор: [synthetic.py](backend/experts/synthetic.py). Интерфейс явно помечает данные как синтетические.

[Проверка финальной интеграции](docs/testing/FINAL_VERIFICATION.json): **44/44 backend-теста**, frontend production build; **Hit@3 7/7** эталонных и **21/21** перефразированных запросов, 2/2 отрицательных сценария. Максимум — **47,777 мс** внутри Django API с PostgreSQL, без HTTP-транспорта и Qwen. Наборы составлены командой, качество на неизвестных запросах жюри не установлено. В предыдущей итерации исправления отрицаний и стажа повысили Hit@3 на том же стресс-наборе с 17/20 до 20/20 ([до/после](docs/testing/CONSTRAINT_FIX_RESULTS.md)); это отдельный исторический прогон.

## Запуск

Стек: **React / TypeScript / Vite / Tailwind / ECharts → Django / DRF → PostgreSQL 16**, Docker Compose. Нужны Docker Desktop и Node.js 24; для ИИ — заранее установленная Ollama с локальной моделью. Интернет нужен при первоначальной подготовке зависимостей, образов и весов; runtime работает локально, без платных API и CDN.

```powershell
# Только на новом ноутбуке: скопируйте .env.example в .env и задайте свои секреты.
# Существующую .env не перезаписывайте; проверьте порты и OLLAMA_*.
npm.cmd ci --prefix frontend
npm.cmd run build --prefix frontend
docker compose up -d --build --wait
```

По умолчанию: **http://127.0.0.1:5173**, API health: **http://127.0.0.1:8000/api/v1/health/**. Порты задаются `FRONTEND_PORT` / `API_PORT` в `.env`; сохраняйте значения демонстрационного ноутбука. Ollama вызывается из backend через `http://host.docker.internal:11434`, модель — `qwen2.5:1.5b` (параметры `OLLAMA_URL`, `OLLAMA_MODEL`, `OLLAMA_TIMEOUT`). Модель автоматически не скачивается. Для подготовленной офлайн-сборки: `docker compose up -d --no-build --pull never --wait`.

Миграции и первичный импорт выполняются автоматически. Существующий реестр сохраняется в PostgreSQL volume; обновление CSV — через интерфейс реестра или `docker compose exec -T backend python manage.py import_experts /app/data/experts.csv`. Не используйте `down -v` для остановки: это удаляет данные.

```powershell
docker compose exec -T backend python manage.py test experts
docker compose exec -T backend python manage.py evaluate_search --queries /app/data/reference_queries.json
docker compose exec -T backend python manage.py evaluate_search --queries /app/data/holdout_queries.json
```

## Ограничения и источники

Словарь RU/KK/EN ограничен; неизвестные условия требуют проверки человеком. Порог 30 секунд относится к подбору, дополнительное сравнение Qwen может выполняться дольше. Это локальный демонстрационный MVP без авторизации и production-развёртывания. Пользователь принимает окончательное решение.

[Кейс AIID](https://hackathon.metu.kz/) · [API-контракт](docs/API_CONTRACT.md) · [QA](docs/QA.md). Данные сгенерированы командой; внешние базы людей не использовались. [Qwen2.5-1.5B-Instruct — Apache 2.0](https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct/blob/main/LICENSE); зависимости зафиксированы в [requirements.txt](backend/requirements.txt) и [package-lock.json](frontend/package-lock.json), лицензии доступны в metadata пакетов.

# AIID — Liquid Glass

The current visual direction uses pearl white #F6FAFF, ice blue #DCE9FF, dark text #0E2347 and cobalt #154BCD. Arial/Segoe UI are local fonts. A large supplied hero-glass-cutout.png is the focal visual. The AIID logo is stored locally and displayed on cobalt because its source pixels are white with transparency.

Header and search form use translucent white surfaces with restrained backdrop blur, solid readable text and cobalt keyboard focus. Operational content remains mostly opaque. Status colors retain explicit labels. Coverage always means recognized condition coverage.

Routes are /, /dashboard, /dashboard/catalog and /dashboard/analytics. Landing focuses on one CTA. Search shows three best matches initially, expands an already received response, and keeps evidence and missing conditions prominent. Catalog uses real API pagination and profile details. Synthetic-data labels remain visible.

Desktop motion has a 1050ms glass entrance, 650ms once-only section reveal, and bounded 60px decorative scroll parallax. Mobile and reduced motion are static. Controls use 100–160ms feedback. No external runtime resources or fonts are used.

BI uses local ECharts with SVG rendering, global demand and filter-scoped current supply. KPI panels are translucent, tables and long RAG text use dense matte glass. Runtime chart filtering has equivalent labelled selects and table buttons.
